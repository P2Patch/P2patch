+package org.jolokia.http;

+/*
+ * Proof-of-vulnerability test for CWE-079 (Reflected XSS via unvalidated JSONP
+ * "callback" request parameter) in org.jolokia.http.AgentServlet.
+ *
+ * Root cause: AgentServlet#sendAllJSON (agent/core/src/main/java/org/jolokia/http/AgentServlet.java,
+ * around line 495-503) takes the "callback" HTTP request parameter verbatim
+ * (read at line 472 via pReq.getParameter(ConfigKey.CALLBACK.getKeyValue()))
+ * and concatenates it, completely unvalidated and unescaped, directly in
+ * front of the JSON payload:
+ *
+ *     String content = callback == null ? json : callback + "(" + json + ");";
+ *     byte[] response = content.getBytes("UTF8");
+ *     ... out.write(response); // sink: raw bytes written straight to the HTTP response
+ *
+ * The response is declared as "text/javascript", but since the callback name
+ * is never restricted to a safe JavaScript-identifier charset, an attacker
+ * can smuggle arbitrary markup/script through the "callback" parameter which
+ * is reflected byte-for-byte into the response body (a classic JSONP
+ * callback-name XSS, e.g. CVE-2018-1000129 class of bug). This test proves
+ * the servlet reflects such a payload completely unsanitized.
+ *
+ * This is deliberately modeled after the project's own
+ * agent/core/src/test/java/org/jolokia/http/AgentServletTest#withCallback
+ * test (same mock setup helpers), just swapping in a malicious callback
+ * value and asserting the dangerous characters survive verbatim in the
+ * response instead of a benign "myCallback".
+ *
+ * A correct fix must validate/neutralize the callback parameter (e.g. reject
+ * or strip anything that is not a safe JS identifier / dotted-path) in ALL
+ * of the following sink locations, not just the one exercised here:
+ *   - agent/core/src/main/java/org/jolokia/http/AgentServlet.java:500 (sendAllJSON, non-streaming servlet path)
+ *   - agent/core/src/main/java/org/jolokia/util/IoUtil.java:36 (streamResponseAndClose, used by both
+ *     AgentServlet's streaming path and JolokiaHttpHandler's streaming path)
+ *   - agent/jvm/src/main/java/org/jolokia/jvmagent/handler/JolokiaHttpHandler.java:364 (sendAllJSON,
+ *     non-streaming JVM-agent path)
+ * Once fixed, this exact malicious callback value must no longer appear
+ * unescaped in the response, so this test will fail (non-zero exit).
+ */
